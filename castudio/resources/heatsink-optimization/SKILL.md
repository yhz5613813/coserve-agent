# 散热器仿真驱动优化

根据当前任务的实际测量提出下一版几何，并保留可核验的设计依据。适用于具有 Gmsh Python 源码的单实体散热器。

## 读取证据

- 以任务给出的基准/最佳源码、geometry、physics、policy 和 history 为依据，核对源码尺寸单位与几何测量的 SI 单位。
- 只有最高温度和质量时，判断全局变化；热点位置、温度梯度和热流路径需要空间场证据。将尚未验证的传热解释写为假设。
- 固定换热系数的固体热模型只能评价该边界条件下的几何变化。增大面积或缩小鳍片间距不能证明实际风量、压降或风机性能改善。

## 选择下一版

先用冻结包围盒计算可编辑区域的剩余空间，再选参数。竖直鳍片允许高度为 `基准最高 z - 鳍根 z`；底板高度已固定且鳍尖已到上限时，不增加鳍高。例如底板 10 mm、鳍高 30 mm、总高上限 40 mm，改成 34 mm 鳍片会得到 44 mm，应在提交前放弃该方向。对 x/y 同样比较真实最小值与最大值。源码里验证 `总高 = 底板 + 鳍高` 不能代替与**冻结基准上限**比较，理由中的“外廓不变”也不是几何证据。

| 当前证据 | 设计决策 |
|---|---|
| 有效候选降低温度且满足约束 | 从最佳源码继续，优先调整一组有因果联系的尺寸，说明为何值得用剩余预算检验。 |
| 有空间温度/热流证据 | 将局部导热截面或散热面积变化与该位置联系；仍需重新求解确认。 |
| 几何或边界检查拒绝 | 从已通过的基准/最佳源码恢复固定接口，修复具体拒绝原因；不原样重试，也不只改注释绕过重复检查。 |
| 改善伴随薄壁、窄间隙或网格警告 | 将收益标为网格敏感；优先探索较稳健的几何，交由服务做相同加密网格复核。 |

安装外形上限、孔位、孔径、**孔深和贯通性**、热源接触区域与显式定位的平面冷却选区均按当前冻结基准保留。整体外表面对流可随可编辑鳍片的拓扑变化重新绑定，换热系数仍冻结。首版孔检查冻结圆柱轴向范围；在孔经过的区域减薄底板也会改变固定接口。释放质量预算时优先调整不影响这些接口的鳍片区域。

结合历史的实际温度、质量、参数变化和失败原因选下一版，不套用固定参数组合。未求解的候选没有实测收益；失败、取消和待验证结果不能替代已验证最佳方案。质量预估只用于设计判断，最终采用独立 STEP 体积与冻结密度的计算。

## 制造与网格判断

已给出加工方式、最小壁厚或间距时遵守它们。未给出时明确标注“制造假设待确认”，避免自行声称可挤压、可加工或可量产，也不把示例尺寸当通用标准。关注鳍片厚度、高厚比、间距、根部连接和刀具/模具可达性。

比较最小几何尺度与当前网格尺度；识别薄鳍片和窄缝的分辨风险。相同加密复核指基准与候选采用一致的网格设置和细化方法，并重新检查局部质量，不要求两种几何有相同节点编号。几何可构建不等于网格充分，粗细网格接近也不是完整收敛性证明。候选只改变几何，不修改材料、功率、环境、换热系数、时间或网格设置。

## 提交与运行

自动优化子代理只通过 `structured_output` 提交现有三个字段：

- `code`：完整自包含、符合任务允许语法的 Gmsh Python 源码，导出 `model.step`。
- `rationale`：用简短段落给出“实测依据 → 可用空间/固定接口检查 → 修改假设 → 质量及制造/网格风险”。检查必须代入候选尺寸，与冻结基准上限比较。例如只有总温度时写“上一版总温度下降；假设继续分配鳍片材料可改善当前固定换热模型，尚无热点定位证据”，不编造预期降温值。
- `changes`：列出实际参数“旧值 → 新值 + 单位”，修复轮说明对应失败原因；用可比较的参数记录支持下一轮判断。

预算、修复次数、停止条件、边界重绑、GPU 求解、排名和复核由任务服务执行。子代理完成提案即结束本轮回答，不自行调用文件、shell、CAD 或仿真工具，也不声称任务已经完成。

普通设计对话中，用户要求自动优化时使用热仿真结果页的“自动优化”；已有任务先查看其状态，避免重复启动。缺少成功基准或建模源码时说明缺项。当前技能使用本任务历史，不代表模型训练或跨项目记忆。
